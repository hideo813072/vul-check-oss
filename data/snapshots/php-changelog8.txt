PHP 8 ChangeLog
8.6 | 8.5 | 8.4 | 8.3 | 8.2 | 8.1 | 8.0
Version 8.6.0
19 Nov 2026
Core:
Fix potential ABI incompatibility when adding fields in patches by adding padding to globals.
Fix function and constant imports in compile_to_ast and add support for grouping.
Fixed bug GH-24668 (zend_set_local_var() leaks the previous value of an existing CV).
Fixed unmapping of an unrelated range when the aligned chunk mmap fails (Marti2203).
Fixed bug GH-25023 (ZEND_CONTAINER_OF() fails to compile with -std=c11).
Fixed AST printing dropping final on class constants and properties, and abstract on properties.
Fixed AST export of readonly anonymous classes dropping the readonly modifier.
Fixed memory leak of a duplicate named argument in new in initializer.
Fixed bug GH-25061 ($x = $x - 1 on null is optimized to PRE_DEC).
Fixed first-class callables to static methods in trait constant expressions resolving to the method of the first using class and bypassing visibility checks.
Fixed bug GH-24184 (System ID not being reinitialized after an Apache graceful restart, potentially causing incompatible OPcache file cache entries to be reused).
Fixed memory leak when an exception already contains the pending exception in its previous chain.
Fixed bug GH-23979 (Nullsafe operator must not flush delayed oplines of an enclosing function).
Fixed memory manager keeping a block reallocated to exactly the size of the next smaller bin in its larger bin, which efree_size() then freed into the wrong one.
Fix throwing behaviour with recursive arrays in VM.
Fixed skipped catch block when switching fibers during exception unwinding (Nicolas Grekas)
Fix escape analysis for objects implementing ArrayAccess.
Fixed GH-23921 (Fibers start with error_reporting = 0 when the error_reporting INI directive is not set).
Deprecated using "let" or "is" as the name of a class, function, or constant, and as an alias in class_alias() and use declarations.
Deprecated using "_" as a constant name and as an alias for a class or constant in use declarations.
Fixed incorrect internal pointer and foreach iterator positions when compacting arrays with holes.
Fix handling of references to typed properties during unserialization of various internal classes.
Fixed bug GH-23752 (Use scoped diagnostic suppression for the global register declarations so the caller's -Wvolatile-register-var state is restored).
Fixed OSS-Fuzz #538730793 (Assertion failure when returning by-ref from closure invoke).
Fixed OSS-Fuzz #540904105 (ASSERT: ast->attr == T_CLASS_C).
Calling is_a() or is_subclass_of() with a string as the first argument when $allow_string is false is now deprecated.
Enabled the TAILCALL VM (--disable-gcc-global-regs) when building with GCC >= 16.
Fixed GH-10497 (Allow direct mutation of objects stored in constants or class constants via OBJ->prop = $val).
Using the return statement in a finally block is now deprecated.
Deprecated "namespace" as a class constant name.
Changed run-tests.php to run in parallel by default, using up to 10 automatically detected workers. Pass -j1 for sequential execution.
Allowed readonly properties to declare default values.
Changed run-tests.php to run test subprocesses without a shell where possible.
Fixed GH-23121 (is_callable() wrongly accepts objects with no get_closure handler).
Passing a 3rd argument to define() is now deprecated.
Naming a function readonly is now deprecated.
Added stateless closure cache.
Implemented partial function application RFC.
Compile array_map() into a foreach() loop when using Partial Function Application as callback.
Fixed bug GH-22263 (reset typed property default on every unserialize failure path).
Fixed bug GH-18847 (SEGV in zend_fetch_debug_backtrace() when the memory limit is reached while the tracing JIT enters a call frame).
Sync Boost.Context assembly with 1.91.0.
Fixed bug GH-22387 (AST pretty-printing drops meaningful parentheses around RHS of instanceof).
Fixed bug GH-15672 and GH-15911 (Stack overflow when an internal function recurses through zend_call_function, such as a self-attached SPL iterator).
abort() instead of exit() on hard OOM.
perf: ZTS: move AG and SCNG into native __thread storage.
Added first-class callable cache to share instances for the duration of the request.
It is now possible to use reference assign on WeakMap without the key needing to be present beforehand.
Added `clamp()`.
Fix OSS-Fuzz #429429090 (Failed assertion on unset() with uninitialized container).
Fixed GH-20564 (Don't call autoloaders with pending exception).
Fixed bug GH-20174 (Assertion failure in ReflectionProperty::skipLazyInitialization after failed LazyProxy initialization).
Enabled the TAILCALL VM on Windows when compiling with Clang >= 19 x86_64.
Deprecate specifying a nullable return type for __debugInfo().
Fixed bug GH-22046 (The unserialize function can lead to segfault when non-Serializable internal classes are serialized back with the C format).
Fixed bug GH-22292 (AST pretty printing does not correctly handle invalid variable names).
Fixed bug GH-22291 (AST pretty printing does not correctly handle braces in string interpolation).
Fixed bug GH-22373 (AST pretty-printing drops meaningful parentheses surrounding property access).
Fixed GH-22422 (zend_arena layout mismatch leaked memory in separately built extensions under AddressSanitizer).
TSRM: use local-exec TLS in PIE executables.
perf: make all static extensions use TSRMG_STATIC.
Fixed bug GH-22257 (type confusion in Exception::getTraceAsString()).
TSRM: make CG, EG, SCNG and AG compile-time offsets.
Deprecate returning values from __construct() and __destruct().
base_convert, bindex, hexdec and octdec now raise a notice when they cannot precisely convert the given number.
Added error_include_args INI option to make the display of function arguments consistent in error output.
Fixed GHSA-8mjj-2r7p-4hg2 (Use-after-free in magic method backtraces can lead to remote code execution). (CVE-2026-129474)
Fixed GHSA-2fjv-p558-g82m (Use-after-free via repopulation of last_fatal_error_backtrace global after shutdown). (CVE-2026-129182)
BCMath:
Added NUL-byte validation to BCMath functions.
Bz2:
Passing an object for the Bzip2 {de}compression stream filter is now deprecated. Use get_object_vars() on the object instead.
Reject oversized input in bzdecompress().
Calendar:
Fixed *tojd() functions and cal_to_jd() truncating arguments outside the int range instead of rejecting them.
CGI:
Fixed GHSA-5j3f-64r7-f564 (PHP-CGI out-of-bounds read and write during PATH_INFO correction). (CVE-2026-129538)
CLI:
Fixed bug GH-24697 (PHP_HTTP_PARSER_STRICT build option doesn't work).
Fixed bug GH-9670 (List -C and -q in the CLI help).
Fixed bug GH-23242 (PHP development server does not support Expect 100-continue flow control).
COM:
Fixed bug GH-25008 (com_event_sink() and com_print_typeinfo() crash resolving an event source with no loaded typelib).
Curl:
Fix use-after-free of CURLOPT_STDERR stream on cloned curl handle.
Fix UAF on clone due to callback data pointer mismatch.
Set content length using CURLOPT_POSTFIELDSIZE_LARGE instead of CURLOPT_POSTFIELDSIZE. This makes it possible to post strings larger than 2GB on some platforms, e.g. Windows.
Improved cURL option validation errors to include the option name.
Raise a value error when the callback registered with CURLOPT_READFUNCTION returns an unexpected long.
Fix bug GH-16513 (curl: exceptions in callbacks do not abort the request).
Added CURLOPT_SEEKFUNCTION and the CURL_SEEKFUNC_OK, CURL_SEEKFUNC_FAIL and CURL_SEEKFUNC_CANTSEEK constants, letting libcurl rewind a streamed request body to resend it on a redirect, multi-pass authentication or a retried reused connection.
Add support for CURLINFO_SIZE_DELIVERED (libcurl >= 8.20.0).
Date:
Update timelib to 2026.03 (Derick)
Fixed bug GH-20503 (Assertion failure with ext/date DateInterval property hash construction).
Fixed bug GH-24350 (MINIT reads a stale external tz database after an in-process module restart).
Added Time\Duration.
Fixed bug GH-11368 (idate() doesn't work for the year -1).
Fixed GHSA-gr4f-wgx5-jpfv (Timezone cache use-after-free can lead to remote code execution). (CVE-2026-129496)
DBA:
Fixed bug GH-24641 (ndbm backend never checks dbm_open() return value, NULL deref on first use after a failed open).
DOM:
Fixed a use-after-free when reflected attribute setters replace an attribute whose child still has a live wrapper.
Fix error paths in dom_xml_serializing_a_document_node().
Fixed reference cycles through DOMXPath and XSLTProcessor php:function callback arguments and return values not being collectable.
Fixed a typo in the DOMException message for INUSE_ATTRIBUTE_ERR.
Fixed bug GH-22624 (use-after-free via DOMNameSpaceNode after DOMDocument::xinclude()).
Fixed Dom\DtdNamedNodeMap integer dimension access so negative indexes return NULL and indexes outside the int range throw ValueError instead of returning the first entity or notation.
Fixed bug GH-22623 (use after free with namespace nodes from XSLTProcessor::registerFunctions())/ (David Carlier)
Fixed bug GH-22554 (use-after-free with XPath callback returning a node from a foreign document).
Removed LIBXML_XINCLUDE from valid options for XMLDocument, as it was a no-op.
Readonly DOM properties are now declared with asymmetric visibility (public private(set)). ReflectionProperty::isWritable() reports them correctly, and external writes raise "Cannot modify private(set) property" instead of the previous readonly modification error.
Fixed Dom\Notation nodes missing tree connection, so that ownerDocument, parentNode, isConnected and baseURI now return correct values, and textContent returns NULL per the DOM specification.
Fixed GHSA-x8r7-mg3g-74hg (Double free during DOM XML serialization). (CVE-2026-129501)
Embed:
Made php-cli functionality available in embed builds.
Exif:
Added support for reading EXIF metadata from WebP images (GH-19904).
FFI:
Fixed bug GH-24582 (Memory leaks in ext/ffi parser when finalize_type() bails out).
Fileinfo:
Fixed bug GH-24289 (finfo::file() reports the wrong argument number for an invalid $filename).
Upgrade to file 5.48.
Fixed bug GH-20679 (finfo_file() doesn't work on remote resources).
Fixed bug #66095 (Hide libmagic dynamic symbols).
FPM:
Fixed crash and stack memory disclosure in the worker output logging with a pool name longer than the message prefix buffer or log_limit.
Fixed GHSA-jm4m-qfqx-967m (PHP-FPM epoll use-after-free can lead to local privilege escalation). (CVE-2026-129291)
Fixed memory leaks of the _GET string on the status page error and HEAD request paths.
Fixed use-after-free of the scoreboard copy when logging invalid status values.
Fixed null pointer dereference in fpm_get_status() when the scoreboard copy fails.
Fixed bug GH-24229 (fcgi_close() passes shutdown() a literal 1, which is SHUT_RD in WASI).
Fixed GHSA-qc49-hpvq-g2w6 (PHP-FPM request smuggling through an unread HTTP request body). (CVE-2026-129289)
Fixed GHSA-3mg3-cr28-46gc (PHP-FPM status endpoint XSS via unescaped user and script fields). (CVE-2026-129292)
FTP:
Fix double free in ext/ftp data_accept() on accept failure.
GD:
Fixed imagetruecolortopalette() error message.
Fixed imageaffinematrixget() to enforce the documented array|float type for the $options parameter.
imagesetstyle()/imagefilter()/imagecrop() check array argument entries types.
GMP:
Added optional $definitely_prime output parameter to gmp_prevprime().
Added gmp_powm_sec().
Added gmp_prevprime().
Fixed GMP power and shift operators to reject GMP right operands outside the unsigned long range instead of silently truncating them.
Fixed GMP integer string parsing to reject strings containing NUL bytes instead of silently truncating them.
Fixed GMP error messages that referenced outdated parameter names.
Fixed bug GH-22549 (Assertion failure / UB on a compound GMP power or shift assignment with a negative exponent).
gmp_fact() reject values larger than unsigned long.
gmp_pow/binomial/root/rootrem and shift/pow operators reject values larger than unsigned long.
GMP exponentiation and shift operators now emit a deprecation warning when converting a float right operand to int loses precision.
Hash:
Fix GOST and Snefru digests of 512 MiB or more.
Fixed hash_file() reporting argument #1 ($algo) instead of argument #2 ($filename) when the filename contains null bytes.
Upgrade xxHash to 0.8.2.
Intl:
Fixed IntlDateFormatter parse functions truncating an $offset below INT_MIN.
Fixed Collator::sortWithSortKeys() allocating fixed 2MiB buffers regardless of array size.
Fixed Spoofchecker methods not recording the ICU error code when an ICU call fails.
Fixed idn_to_ascii() and idn_to_utf8() reporting argument #2 ($flags) instead of argument #3 ($variant) for an invalid IDNA variant, and the domain length error message printing a literal "d" instead of the limit.
Added static methods IntlDatePatternGenerator::getSkeleton() and IntlDatePatternGenerator::getBaseSkeleton().
Fixed Collator::sort(), collator_sort(), Collator::asort(), and collator_asort() to report UTF-8/UTF-16 conversion errors through the intl error handler instead of emitting a warning and continuing with an empty string.
Implemented GH-20255 (Add a predefined calendar constant in IntlDateFormatter for the proleptic gregorian calendar).
Added SpoofChecker::areBidiConfusable().
Added SpoofChecker::getBidiSkeleton().
Added SpoofChecker::getSkeleton().
Fixed grammatical issues in Normalizer invalid form and IntlCalendar time zone offset error messages.
Removed the dependency on the ICU IO library.
Fixed NumberFormatter::parse() and NumberFormatter::parseCurrency() to reject offset values outside the 32-bit range instead of silently truncating them.
IntlDateFormatter::parse()/datefmt_parse() and IntlDateFormatter::localtime()/datefmt_localtime() now raise TypeError when the offset argument is not of type int.
Fixed malformed ResourceBundle::get() error message when fallback is disabled.
Added Locale::getDisplayKeyword() and Locale::getDisplayKeywordValue(), with the alias of locale_get_display_keyword() and locale_get_display_keyword_value() respectively.
Added IntlNumberRangeFormatter class to format an interval of two numbers with a given skeleton, locale, collapse type and identity fallback.
Added grapheme_strrev (Yuya Hamada)
Passing a non-stringable object as a time zone to Intl time zone argument handling now raises TypeError instead of Error.
IntlBreakIterator::getLocale() now raises ValueError for invalid locale types.
Fixed MessageFormatter::parse() and parseMessage() returning PHP_INT_MIN as float rather than int on 64-bit platforms.
Fixed UConverter::transcode() silently truncating from_subst and to_subst option lengths greater than 127 bytes.
Fixed IntlIterator::current() to return NULL instead of an undefined value when the iterator is not positioned on a valid element.
IO:
Added new polling API.
JSON:
Fixed json_encode() leaving the recursion guard set on objects with hooked properties after running out of memory while escaping a property name.
Fixed json_encode() silently narrowing $depth values outside the int range, which wrapped to an unrelated depth.
Fixed json_encode() continuing to encode after an array or object key failed to encode.
Report unterminated JSON strings as syntax errors.
Improve performance error position tracking during JSON decoding.
Enriched JSON last error / exception message with error location.
LDAP:
Fix crash in ldap_exop_sync() when $response_data is omitted.

Fixed bug GH-23958 (truncated encoding names resolving to full names).
Fixed out-of-bounds read in php_mb_rfc1867_getword() on a multibyte lead byte at the end of a multipart field name.
Updated Unicode data tables to Unicode 18.0 (Yuya Hamada)
Passing objects to mb_convert_variables() is now deprecated.
ini_set() with mbstring.detect_order changes the order of mb_detect_order as intended, since mbstring.detect_order is an INI_ALL setting.
Added GB18030-2022 to default encoding list for zh-CN.
mbregex has been deprecated.

Added mysqli_quote_string() and mysqli::quote_string().
